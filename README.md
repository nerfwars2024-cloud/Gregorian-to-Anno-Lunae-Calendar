# Gregorian-to-Anno-Lunae-Calendar
My name is Luke Johnson and i created a calendar system known as Anno Lunae. The year is 173 days long because it is based off of the Nasa average season for possible solar eclipses. The reason that i came up with this Calendar is because i noticed something; 6 synodic months is 177 days and the time between solar eclipse periods is 173 days.
